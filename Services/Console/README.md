# LEAN web console

Plan step s5.1. A React + Vite + TypeScript single-page app served by its own nginx container (`console` image,
`Services/Dockerfile` target `console`). nginx serves the SPA at `/` and proxies `/api` (and `/openapi`) to
`api-gateway`, adding the API key from the container environment, so the browser bundle carries no credentials and
the console talks only to the public gateway API.

| Page | Route | Gateway calls |
| --- | --- | --- |
| New backtest | `/backtests/new` | `POST /api/v1/algorithms` (Python / edited C#), `POST /api/v1/backtests` |
| Jobs | `/jobs` | `GET /api/v1/jobs` (kind/status filters, cursor paging), `POST /api/v1/jobs/{id}/cancel` |
| Backtest detail | `/jobs/{id}` | `GET /api/v1/jobs/{id}`, `/result`, `/charts/Strategy Equity`, `/charts/Drawdown`, `/orders`, `/logs`, `/result/download`; `POST /api/v1/reports`, `GET /api/v1/reports/{id}`, `/reports/{id}/html` |
| Optimizations | `/optimizations`, `/optimizations/{id}` | `POST /api/v1/optimizations/estimate`, `POST /api/v1/optimizations`, `GET /api/v1/optimizations/{id}`, `GET /api/v1/optimizations/{id}/children` (results grid) |
| Live | `/live`, `/live/{id}` | `POST /api/v1/live`, `POST /api/v1/live/{id}/stop`, `/result`, `/orders` (positions are net filled orders), `/logs` |

Samples: `npm run samples` (run by `dev`/`build`) copies every standalone algorithm of `Algorithm.CSharp` and
`Algorithm.Python` into `public/samples/` with an `index.json`. An unedited C# sample runs as a `builtin` class from
the worker image; Python (and edited C#) source is uploaded through `POST /api/v1/algorithms` first, and the worker
compiles uploaded C# with Roslyn before starting the engine (errors fail the job with `compile-error`).

## Typed client

`src/api/schema.d.ts` is generated by [openapi-typescript](https://openapi-ts.dev) from the gateway contract
`docs/architecture/contracts/openapi/gateway.openapi.yaml`; `src/api/client.ts` wraps it with `openapi-fetch`.

```bash
npm run gen:api        # regenerate from the checked-in contract
npm run gen:api:live   # or from a running gateway's merged /openapi (GATEWAY_OPENAPI_URL)
npm run check:api      # fails when schema.d.ts is stale (run by the image build)
```

## Run

```bash
# whole stack (from the repo root); console on http://127.0.0.1:5090
docker compose --profile infra --profile orchestrator --profile results --profile report --profile workers \
  --profile optimizer --profile gateway --profile console up -d --build --wait
deploy/compose/verify-console.sh

# dev server with HMR against a running gateway (proxy adds the key like nginx does)
npm ci && LEAN_GATEWAY_URL=http://127.0.0.1:5080 LEAN_API_KEY=lean-dev-api-key npm run dev
```

| Variable | Where | Default |
| --- | --- | --- |
| `CONSOLE_API_KEY` | compose → `LEAN_API_KEY` in the container | `GATEWAY_API_KEY`, then `lean-dev-api-key` |
| `CONSOLE_PORT` | compose host port | `5090` |
| `LEAN_GATEWAY_URL` | container | `http://api-gateway:8080` |
| `NGINX_RESOLVER` | container (DNS for the gateway host; kube-dns in Kubernetes) | `127.0.0.11` |

The console is a trusted operator UI: anyone who can reach it acts with its API key, so publish it only on a
private network or behind an authenticating proxy (compose binds it to `127.0.0.1`).

```bash
npm run typecheck && npm test && npm run build
```
